# fieldnote

fieldnote is a note-taking CLI for the terminal.

## Usage

```bash
# Create a new note
fieldnote add "Meeting notes for the launch sync"

# List your notes
fieldnote list

# Read a note
fieldnote show <id>

# Search your notes
fieldnote search "launch"
```

Notes are stored as plain text, so they play nicely with git, editors, and scripts.
